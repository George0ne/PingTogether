PingTogether 0.5.0 — macOS 桌面标记

安装与启动
将 PingTogether.app 拖到 Applications（应用程序），然后双击启动。
屏幕顶部菜单栏会出现黄色问号，点击可查看功能、声音设置和退出。
支持 macOS 12 或更新版本，Apple Silicon 和 Intel Mac。
不需要安装 LOL、联网或打开开发工具。

快捷键
⌥ Option + Q（按住）：在鼠标位置打开轮盘，移动选择，松开 Q 或 Option 发送。
停在轮盘中心松开或按 Esc：取消。
⌃ Control + ⌥ Option + Q：直接打问号。
⌥ Option + A（按一下）：进入框选模式，按住鼠标拖框，松开后显示淡黄底纹并打问号。
⌥ Option + X：立即清除底纹。
框选时 Esc 或右键：取消。

底纹持续 6 秒；问号等 Ping 动画持续约 2 秒。
完成后的底纹和标记不会拦截鼠标操作。
标记和底纹固定在屏幕位置，不会跟随文献滚动；翻页前可以先清除。

声音与共享
菜单栏提供“测试提示音”和“静音”。没有声音时先检查 macOS 系统静音、音量和输出设备。
演示时请选择共享整个屏幕；朋友要听到提示音，共享软件还需要支持并开启系统音频。
目前是本地版，不包含好友联网同步。

退出与卸载
点击菜单栏黄色问号 → 退出 PingTogether。
退出后将 Applications 中的 PingTogether.app 移到废纸篓即可移除应用。

版本说明
此软件包为本机临时签名版本，尚未经过 Apple Developer ID 签名和公证。
在另一台 Mac 首次启动时，可能受到 macOS 安全检查限制。
